# tamaclaude for herdr

A token usage popup, palettes and an optional look for [herdr](https://herdr.dev):
herdr's colors from your palette, a status area right of the tabs (branch,
tokens today, limits, clock) and colored sidebar rows.

```sh
herdr plugin install fabandrade88/tamaclaude/herdr
herdr plugin action invoke tamaclaude.stats          # the usage popup
herdr plugin action invoke tamaclaude.theme-install  # the tamaclaude look
```

Needs herdr 0.9.0+ and Node.js 18+. Screenshots and details:
[the main README](https://github.com/fabandrade88/tamaclaude#readme).
